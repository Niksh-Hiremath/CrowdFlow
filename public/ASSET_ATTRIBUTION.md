# Layout asset attribution

CrowdFlow stores these real venue-layout images locally so graph extraction and
the confirmation workflow can be demonstrated without relying on third-party
image hosts. The files are shown as simulation inputs; their presence does not
imply that the venue owners endorse CrowdFlow.
